# ReoGrid Lite — React Example

## Setup

```bash
npm install
npm run dev
```

A Yarn 4 lockfile is also included, so `yarn install && yarn dev` works too.

## Notes

- Requires React 17+
- Uses `@reogrid/lite` ^1.6.0 (listed in `dependencies`)
- The grid fills the remaining viewport height via `flex: 1`
